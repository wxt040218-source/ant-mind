# 最小版开发路线

2026-11-05 规划已确认；目前停在规划归档，不开始实现。范围与数值见 [MVP_SPEC.md](MVP_SPEC.md)。未承诺工期，人员分工与许可证待约定。

## M0 · 规划归档

- [x] 创建公开仓库并上传立项资料。
- [x] 完成五轮 36 项设计选择，用户确认整体理解与初值。
- [x] 统一最小版规格、玩法、技术栈与架构。
- [ ] 与共同开发者约定分工和许可证。

## M1 · 最小接入与导出验证（尚未开始）

- [ ] 锁定 Godot .NET、SDK 与导出模板版本。
- [ ] 最小窗口可导出并在 Windows x64 启动。
- [ ] 当前 Codex 通过项目级 MCP 读取实时状态并提交可观察改动。

验收：实际工具调用与桌面行为互相对应，不仅是配置文件存在。

## M2 · 世界与默认采运

- [ ] 种子地图、蚁巢、一种资源、工蚁与默认程序。
- [ ] 寻找、目标移动、拾取、交付与库存统计。
- [ ] 随机资源补充、人口约束、增员、5 级大脑与通用信息素。

验收：不连接 Agent 也能持续运行；无凭空资源、重复计分或越过约束的消费。

## M3 · 程序与可观察性

- [ ] 受限文本 DSL、计费、有限记忆与局部感知。
- [ ] 版本校验、Tick 边界替换、回滚、默认恢复。
- [ ] 只读程序和个体目标、分支、预算、信息素与错误记录。

验收：坏版本被拒绝，超预算有记录，换程序的个体记忆与目标按规则清除，世界持续运行。

## M4 · 完整交互与确定性

- [ ] Agent 全图／仅已发现模式与记录。
- [ ] 暂停、单步、1／2／5 倍速。
- [ ] 手动存读档、配置与随机状态还原。
- [ ] 同输入回放一致，算法比较从相同起点进行。

验收：信息过滤、存读档和倍速不破坏世界规则。

## M5 · 用户指令优化与完整最小版

- [ ] 按用户要求完成一次单轮与一次多轮优化。
- [ ] 展示程序改动、发展支出及效率差异，如实报告收益或退步。
- [ ] 在目标 Windows 环境运行完整导出包。

验收：玩家能观察、理解并要求 Agent 改变蚁群的工作方式。

多职业、复杂地形、天气、战斗、地下巢穴、排行榜和多人竞技均不在本轮范围。
