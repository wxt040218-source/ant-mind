# 文明制度与殖民地纪元迁移指南

版本：0.1.0  
适用：wire19 / content16 / save6（S1）

## 1 · 版本三跳

| 面 | 旧值 | 新值 |
|---|---|---|
| `Protocol.Version` | 18 | 19 |
| `content/world.json schemaVersion` | 15 | 16 |
| `SavedGames.Format` | 5 | 6 |

`docs/contracts/` 下四份 S0 冻结契约不修改；`PROJECT_STATUS.md` 是上游 v0.19 长记录，本轮不动。`docs/README.md` 在本仓库不存在，因此没有索引需要同步。

## 2 · 新增持久状态

`WorldState` 增加 `creature_seed`、`nest_seed`、`nest`、`institution`、`blocked_cells`、`observed_chambers` 六个持久字段。`ActiveParameters` 是每 Tick 由 `GameSession.Advance` 在跑规则之前注入的只读快照，标记 `[JsonIgnore]`，不落盘、不读写主 `RandomState`。独立子种子由总纲 §2.1 的纯函数 `Simulation.DeriveSubseeds(ulong seed)` 派生。

`content/world.json` 新增 `institutions`、`creatures`、`nestLayout` 三段；字段名按契约用 snake_case，DTO 通过 `[JsonPropertyName]` 对齐。`ContentLoader` 的 `UnmappedMemberHandling.Disallow` 保持开启。

## 3 · 制度字段与命令

五字段封闭白名单及默认值：

| 字段 | 默认 | 档位 |
|---|---|---|
| `reserve_policy` | `balanced` | `strict` / `balanced` / `loose` |
| `ration_policy` | `weakest_first` | `queen_first` / `weakest_first` / `worker_first` / `equal` |
| `labor_policy` | `balanced` | `balanced` / `haul_first` / `build_first` / `guard_first` |
| `defense_policy` | `measured` | `early` / `measured` / `late` / `never` |
| `admission_policy` | `fresh_first` | `fresh_first` / `bulk_first` / `near_first` / `type_first` |

`SetInstitution` 改一字段；`RollbackInstitution` 把历史快照恢复为一个**新版本**，不回拨 `Version`、不删历史。两者都经 Runtime actor、复用 `requestId` receipts 幂等，且只写 `WorldState.Institution`，不写 `FoodStore`、`Economy.Created`、`Generated`、`FirstAdmissionPoints` 或 `DevelopmentValue`。`History` 上限 32，超出丢最旧。失败码逐字：`unknown_institution_field`、`invalid_institution_tier`、`institution_version_not_found`、`institution_rollback_conflict`、`institution_reason_too_long`、`duplicate_request_id`。

`CommandKind` 尾部一次性追加六个成员：`SetInstitution`、`RollbackInstitution`、`PlanChamber`、`DigChamber`、`UpgradeChamber`、`CancelChamber`。后四个是 S2 预留枚举，S1 不实现行为。`GameCommand` 同时追加 `institution_field`、`institution_tier`、`target_institution_version`、`chamber_x`、`chamber_y`、`chamber_type`，使 S2 不再改变 wire 形状。

## 4 · 消费方式

制度不新增 `IWorldRule`、不占 `Order`；`GameRules.Create` 仍是 22 条规则。`InstitutionMechanics.Resolve(world)` 产出每 Tick 纯整数参数快照，消费点如下：

- `reserve_policy`：`EatingRule` / `ClaimCleanupRule` / `ProductionActionRule` / `TechnologyProgression.Pay` / 命令层 reserve 校验读 `EffectiveReserve`；`SetMinimumReserve` 命令仍写 `world.Config.MinimumReserve`，形成 config 基线与制度档位双轨。
- `ration_policy`：`EatingRule`、`ClaimRule` 用稳定排序键；不改 `HealAmount` / `EatingTicks=40`。
- `labor_policy`：`WorkRule` 乘工种权重；`ProductionActionRule` 让 chef 的 process 意图先处理。权重默认 100，整数乘除保持旧行为精确等价；不改 `workUnitsPerExperience=10`、不改 `SpeciesProgramCatalog`。
- `defense_policy`：`CombatRule` / `FollowRule` 威胁达阈值时 guard 组前置；`QueenCommunicationRule` 缩短通信冷却。手动 `Attack` 语义与 `EnemyDamage=2` 不变。
- `admission_policy`：`InteractionRule` 只重排 Deliver 意图的处理顺序，`Ants` 存储顺序与 `Economy.Admit` / `FirstAdmissionPoints` 判定不变；`ClaimRule` 用同键裁决。

兼容口径：没有 `ActiveParameters` 的直接 `rule.Apply` 单元测试自动回退到旧的 `world.Config.MinimumReserve` 与旧顺序，所以旧 460 条检查逐帧不变。真实 actor 世界由 `Advance` 注入快照后才启用制度参数。

## 5 · DSL

`AntDsl.cs` 常量 `MaxSourceLength=8192`、`MaxNodes=512`、`MaxNesting=8`、`MaxRepeat=16`、`MemorySlots=16` 全部不变，`GroupValue` 不新增成员。

- `set_institution("field","tier")`：编译期校验封闭白名单，运行期只在 `Decision` 记录只读意图，不改全局制度；真改全局只走 `CommandKind.SetInstitution`，避免多蚁同 Tick 竞争破坏确定性。
- `institution("field")`：返回全局唯一整数档位码 1..19，可与 19 个 Builtin 常量（如 `reserve_balanced`）比较；纯 int DSL 没有自由字符串类型。
- `institution_version`：无参 Builtin，返回当前制度版本。

## 6 · MCP

新增第 16 个只读工具 `inspect_institution`，返回 `{version, appliedTick, reason, fields{五字段}, historyCount}`，不返回 History 全文、巢穴全图、隐藏野怪或 player 全图。`get_actions` 的 `protocolVersion` 随常量为 19；`command` 追加 `institutionField` / `institutionTier` / `targetInstitutionVersion` 三个可选参数。S1 不接 chamber 参数，S2 后工具数固定 17。

两处工具数断言已同步：`AgentMcpCheck.cs` 的 `names.Count==16`、`McpCheck.cs` 的 `GetArrayLength() != 16`。

## 7 · 旧档迁移

`SaveMigration.Upgrade` 的链为 `4/15..17 → 5/18 → 6/19`。注意 4→5/18 一级显式写死 5/18，不能引用已升到 6/19 的常量，否则会跳过 5→6 级。`UpgradeV5` 六步：

1. 由旧档 `World.RandomState` 确定性派生 `CreatureSeed` / `NestSeed`，不读写主随机源。
2. 补 9×9 `NestLayout`：仅中心 `(4,4)` / index 40 为 `core`、`active`、`discovered=true`，其余 80 格 `empty` / `planned`。
3. 补 `InstitutionState` Version=1、五默认档位、`Reason=migrated-from-save5`、`AppliedTick=save.World.Tick`、History 含初始版本。
4. 补 `BlockedCells=[]`、`ObservedChambers=[40]`。
5. `EnemyView` 七个标量补默认：`creature_kind="predator_beetle"`、`carcass_food_type="meat"`、`block_cells=0`、`herd_id=0`、`last_graze_tick=-1000000`、`target_chamber_x=-1`、`target_chamber_y=-1`。
6. `ObservedBuildings`、旧工地 `ConstructionItem=fiber`、`cache.CanFeedAnts` 保持不动；`NormalizeLegacyJson` 不新增分支。

迁移只在内存候选上执行，不回写旧档。`SavedGames.Validate` 增补制度、巢穴、子种子、BlockedCells、ObservedChambers 与 EnemyView 字段级校验。

## 8 · 检查与验证

`tools/AntMind.Checks/InstitutionCheck.cs` 注册进 `Program.cs` 的单一 `Check(bool,label)` 计数器，覆盖制度契约 §8 的 14 条 `institution/...` label，并复用总纲四条不变式 label。`All {checks} architectural checks passed.` 仍只有一行，N=460+实跑新增数。

全链构建、`AntMind.Checks` 实跑、同种子逐帧一致、旧档字节不变、commit / push / `ls-remote` 回读结果以本轮交付回报为准。

## 9 · S2 / S3 边界

S1 只定巢穴与野怪存档形状，不实现 `core.nest-construction(33)` 或 `core.creature-ecology(1)`，不读 `CreatureSeed` / `NestSeed` 驱动生态，不改 `EnemySpawnRule` 或 `AddFood`。`NestLayout` 的 C# 属性用 `Width` / `Height`，JSON 名仍为 `grid_width` / `grid_height`，与冻结契约的序列化形状一致。
