# 最小版玩法说明

2026-11-05 已确认。本文为导读，完整规则与初值见 [MVP_SPEC.md](MVP_SPEC.md)。原限时挑战、多职业和生存消耗建议已被本次最小版决定替代。

## 核心循环

天然资源随机出现 → 工蚁探索、拾取、搬回、交付 → 公共仓库积累 → 增员工蚁或升级大脑 → 按玩家指令由 Codex 改程序 → 观察效率与行为变化。

不限时经营，无胜负倒计时。先只有一种工蚁，每只都能完成全部采运流程；没有单独采集职业、加工环节或幼虫阶段。

## 算法与信息素

同类共享一份受限文本程序，但每只蚂蚁有独立记忆和目标。程序控制目标选择、拾取、交付、信息素释放与跟随，引擎执行基础移动并检查动作是否合法。

信息素只有一个通用通道，含义由 Agent 自己设计。它会衰减但不扩散，游戏不自动释放或跟随。玩家可以查看浓度覆盖图。

蚂蚁局部感知，玩家全图可见。Agent 可随时切换全图与仅已发现模式，切换不改变蚂蚁感知；严格比较局部策略时需要从新一局开始。

## 经营与升级

资源存入公共仓库，Agent 在玩家最低储备与人口约束内自主增员及升级，记录理由和支出。大脑共 5 级，只提高决策预算与频率，速度、负载与感知不变。

显示库存、累计首次交付量、近 60 模拟秒吞吐量、人口、等级、发展支出和运行错误。没有饥饿、死亡、维护消耗和离线发展。

## 玩家观察与干预

玩家从 Codex 聊天中提出发展目标，要求单轮或多轮优化。游戏显示连接状态、最近操作与理由，支持查看程序版本、选中个体查看记忆及决策分支、回滚与恢复默认程序。

Agent 思考时旧程序持续执行。程序替换或回滚会清空个体程序记忆与旧目标，保留世界状态。支持暂停、单步、1／2／5 倍速及一个手动存档槽。

## 比较算法效果

比较从同一存档、相同模式与相同模拟时长开始，记录程序版本、人口、等级、消费和操作。报告真实改进或退步，不将不同发展投入产生的差异全部归因于算法。

最小版不做天气、战斗、地下巢穴、多职业或排行榜；未来是否加入另行讨论。
