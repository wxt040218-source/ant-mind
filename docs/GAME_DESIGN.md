# 最小版玩法说明

2026-11-07 更新至 v0.3。本文为导读，完整规则与初值见 [MVP_SPEC.md](MVP_SPEC.md)。

## 核心循环

天然资源随机出现 → 侦察蚁探索／搬运蚁运输 → 拾取、回巢、交付 → 公共仓库积累 → 按蚁种增员或升级共享大脑 → Agent 按种类编写程序 → 观察效率与行为变化。

不限时经营，无胜负倒计时。首批为侦察蚁和搬运蚁，身体速度、视野和负载不同；两类都能探索、拾取和交付。侦察蚁可少量运输但负载时速度明显下降。

## 算法与蚁后通信

同种类蚂蚁共享一份受限 DSL 程序，每只蚂蚁有独立的感知、16 槽记忆、目标和决策记录。侦察蚁与搬运蚁程序版本相互独立。程序选择目标、拾取、交付和基于蚁后数据的行为，Core 按该种类身体参数执行移动并检查动作是否合法。

蚂蚁通过程序显式调用 report_discovery 上报发现、request_queen_info 下载缓存；进入蚁后范围不自动通信。范围外保留局部感知、旧缓存、记忆和待上传发现。默认半径 16 格，玩家可以查看覆盖圆。

蚂蚁局部感知，玩家全图可见。Agent 可随时切换全图与仅已发现模式，切换不改变蚂蚁感知；严格比较局部策略时需要从新一局开始。

## 经营与升级

资源存入公共仓库，Agent 在玩家最低储备与人口约束内自主选择蚁种增员及升级，记录理由和支出。大脑共 5 级，首版提高两种类共同的决策预算与频率；身体速度、负载和感知依蚁种定义。

显示库存、累计首次交付量、近 60 模拟秒吞吐量、人口、等级、发展支出和运行错误。没有饥饿、死亡、维护消耗和离线发展。

## 玩家观察与干预

玩家从 Codex 聊天中提出发展目标，要求单轮或多轮优化。Agent 通过 MCP 按蚁种提交、查看和回滚程序。桌面显示两种程序、版本与种类统计；点击个体查看记忆、目标、预算、最近分支和错误。

Agent 思考时旧程序持续执行。程序替换或回滚在下一个 Tick 边界生效，只清空目标种类成员的程序记忆与目标。支持暂停、单步和 1／2／5 倍速。手动存档仍待 M4 实现。

## 比较算法效果

比较从同一存档、相同模式与相同模拟时长开始，记录程序版本、人口、等级、消费和操作。报告真实改进或退步，不将不同发展投入产生的差异全部归因于算法。

最小版不做天气、战斗、地下巢穴、多职业或排行榜；未来是否加入另行讨论。
