# 地图交互动效 v0.17.1

2026-11-10。纯Avalonia桌面表现更新，wire16／content13／save4不变。

## 当前效果

- 拾取、采集、取出：蚂蚁轻弹，资源点收缩回弹并散出少量像素粒子。
- 交付、存入、转交：发送方挤压后回弹；已识别的接收方回弹，最多三颗食物像素沿短弧飞向接收处。携带物标记随身体一起运动。
- 有效施工／加工劳动：蚂蚁和工位轻点、小火花；建成或观察到产出增加时使用更明显的完成反馈。
- 攻击：向已知目标小幅前冲；受击：短促横向抖动和暖红粒子。回血使用绿色加号，新生／晋级使用短弹跳。

使用现有透明PNG和最近邻采样，保留职业形象；身体围绕脚底做非均匀缩放和位移。血条、等级和选择框保持稳定。画面偏移不参与碰撞、交互距离、命中测试或拥挤间距计算；缩放沿既有相机处理。

## 扩展入口

- `src/AntMind.Desktop/MapFeedback.cs`：比较连续的公开Snapshot，生成MapPulse；MapFeedbackKind与Pose统一描述动作风格。
- `src/AntMind.Desktop/WorldCanvas.Feedback.cs`：精灵变换、像素粒子、交付弧线和局部动画定时器。
- `src/AntMind.Desktop/WorldCanvas.cs`：保留原来的世界布局／点选，在绘制时应用上述表现。

单次反馈约620ms，定时器间隔16ms，仅有活动反馈时额外重绘；空闲自动停止，离开可视树清理。持续劳动至少间隔420ms触发，受击反馈短期优先，粒子记录最多256条。基于本地单调时钟，不调用游戏随机数，不写Runtime，不新增模拟事件或持久字段。

首次显示、加载后WorldId变化、倒退Tick或超过120Tick的快照断档会清空效果，避免把读档与集中补帧当作一串交互。相同Tick轮询不重复触发；暂停后已触发的短动效可自然结束，单步也能看到回弹。表现只用已允许公开的信息，不读取未知对象。

这是按桌面快照变化做的视觉反馈，10Hz观测与高倍速可能合并部分动作，不是完整动作回放；不承诺每个被跳过的Tick都生成动画。新动作可增加明确的快照识别及对应动效，不能为美术反馈直接改变Core规则。
