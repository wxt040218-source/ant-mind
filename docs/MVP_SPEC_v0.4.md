# Ant Mind 最小游戏规格 v0.4

2026-11-07：用户要求取消信息素，改用蚁后范围通信，并向 Agent 开放所有现有玩法按钮接口。本文件取代 v0.3；历史见 MVP_SPEC_v0.3.md。

## 世界与蚁种

无游戏引擎；C# / .NET 10、Avalonia、官方 MCP SDK。固定 20Hz、每格 1000 整数单位、固定种子、Runtime actor 唯一写入。平面无障碍地图、一个固定蚁巢、一种持续补充的资源；不限时，无饥饿、死亡或维护消耗。

初始侦察蚁／搬运蚁各 5 只。侦察蚁空载／满载速度 150／90、负载 1、感知半径 6；搬运蚁为 120／100、负载 4、感知半径 3。负载减速线性计算。增员、五级共享大脑、库存储备和人口约束沿用原配置；初值全部位于 content/world.json（schemaVersion 3）。

## 蚁后通信

取消信息素的产生、衰减、跟随和显示。蚁后位于巢穴中心，通信为固定点欧氏距离圆形，默认半径 16 格，边界在范围内。

每只蚂蚁只自动感知自己的局部资源。连通时自动上报最新资源发现、读取蚁后汇总；范围外不读取蚁后数据，局部感知和 16 槽程序记忆继续有效。离线发现保存在个体待上报记录中，重新进入范围后上传。通信不依赖交付食物。

蚁后没有全图真值，只保留已上传的信息及观察时间。资源耗尽由再次实际观察后修正；旧记录可能过期。空资源记录保留时间戳，避免晚到的旧报告覆盖更新。传输在稳定的通信规则中发生，顺序为通信→程序→移动→交互→刷新；运动离开范围后，下一次决策立即停止读取。

玩家可看全图，外部 Agent 可调用 Visibility 切换已发现／全图；这一权限不改变单只蚂蚁的通信或感知边界。模型已读取的信息无法撤回。

## 按蚁种编程

Scout 和 Hauler 各有一份共享受限 DSL、独立版本历史和默认程序；每只蚂蚁记忆独立。程序更新／回滚在 Tick 边界应用，清空目标种类成员的程序记忆与目标，保留位置、负载和通信报告。错误版本拒绝；超预算结束当次决策并记录。程序动作只有 move_to、pickup、deliver、wait；细节见 ANT_DSL.md。

## 操作 API

全部现有玩法按钮调用同一 Runtime 命令队列；MCP 开放暂停、运行、单步、倍速、产卵、按蚁种孵化、升级、信息模式、程序提交与回滚。另有通信半径、最低储备和人口上限设置。get_actions 返回完整命令清单，validate_program 提供无副作用的程序校验。参数、调用顺序及未来扩展约定见 AGENT_API.md。

Agent 可提交操作，实际结算仍检查库存、等级、人口、合法参数与 revision。不可直接写世界状态。尚未实现的存读档不伪装成可用 API。

## 桌面与验证

桌面显示通信覆盖圆、蚁种统计、程序版本、个体连接状态和最近决策。右侧主菜单选择蚁种，详情层显示共享大脑升级（含费用、预算、间隔）、该种类孵化和查看代码入口；代码页只读展示对应蚁种程序与历史，支持逐层返回。共享大脑升级仍同时影响两类蚂蚁。暂停、单步和 1／2／5 倍速沿用。

必须验证范围内／外／边界、离线发现回传、DSL 数据隔离、确定性、预算、资源守恒与 MCP 调用。手动存读档及当前 Codex 会话实际 MCP 接入仍待后续完成。


## 蚁后菜单与通用卵（2026-11-07 补充）

主菜单增加蚁后入口，页面包含产卵按钮、待孵化卵数量、累计产卵／孵化数、通信范围数字设置及应用按钮。蚁后生产的卵不绑定种类；玩家进入任意已配置蚁种的菜单消耗 1 枚卵，选择孵化为该种类。

初始卵 0，每枚生产成本默认 20 资源，复用原增员成本配置；首版生产和孵化均为即时单次操作。孵化不额外扣资源。产卵受最低库存约束，孵化受实际蚂蚁人口上限约束；失败不扣卵。卵可储存，现有初始蚁群不受影响。直接增员接口退出使用。

生产／孵化及通信范围设置同时提供 MCP API。协议与快照版本升为 4，内容 schema 仍为 3（配置结构未变）。升级仍使用共享大脑规则。
