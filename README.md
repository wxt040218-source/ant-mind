# ANT MIND · 蚁智（暂定名）

**做一个给 AI 玩的蚂蚁游戏。人定方向，AI 写程序，蚁群用食物运输效率证明策略。**

我们想做一个简约像素风的蚁群经营游戏：蚂蚁寻找、采集食物，再搬运回蚁后所在的蚁巢。玩家给 AI 一个大致的发展方向，AI 自己安排分工，并编写、调整各职业蚂蚁的行为程序。

比如你可以说：

> 先别急着增加蚂蚁，看看为什么采集出来的食物一直堆着。多安排一些搬运蚁，减少空跑，让每分钟运回来的食物更多。

有意思的地方是：同样的地图、同样数量的蚂蚁，换一套 AI 程序，最后能多运回来多少食物？

**目前是构思与立项阶段，仓库包含项目介绍、设计草案和开发路线，还没有可运行的游戏或 AI 接入。**

## 核心玩法

1. **人定方向**：通过自然语言告诉 AI 想要怎样发展。
2. **AI 管战略**：分析瓶颈，决定繁殖、职业比例和资源优先级。
3. **AI 写职业程序**：同职业蚂蚁共享一套程序，每只蚂蚁有独立状态和记忆。
4. **蚁群实际执行**：探索、采集、装载、运输、交付。
5. **看数据再优化**：保留程序版本，对比运输效率，支持回滚。

蚂蚁先分成两大类：**生产／资源获取类**和**搬运类**，各自逐步解锁多个职业。职业升级会增加程序的计算预算，或缩短决策间隔；感知和记忆能力也可以作为后续成长方向。

地图上有天然资源，后续加入资源刷新、降雨等事件，让 AI 需要根据情况改变做法。

## 已经确定的方向

| 内容 | 选择 |
| --- | --- |
| AI 参与方式 | 战略指挥 + AI 编写职业程序，两层结合 |
| 第一阶段模式 | 单人挑战 |
| 核心目标 | 在规定时间内，提高成功运回蚁巢的食物量 |
| 美术方向 | 简约像素风 |
| 长期方向 | 让不同 AI 的蚁群策略可以比较，后续再考虑排行榜和竞技 |

## 第一版先做什么

先验证一件事：**AI 改了职业程序以后，蚁群的实际效率能不能提高，而且人能看懂它为什么提高。**

- 一张小地图、一个蚁巢、少量天然食物。
- 采集蚁和搬运蚁，先用内置程序跑通完整流程。
- 固定地图种子、固定挑战时长与初始条件。
- 显示送达食物总量、食物／分钟、空载率和蚂蚁分工。
- 再接入 AI 战略与职业程序生成，加入版本对比。

多人联机、复杂地下巢穴、战斗和完整生态系统留到后面。技术方案还在讨论，优先考虑浏览器版本，具体引擎、模型和运行方式一起确认。

## 想一起做？

可以从自己感兴趣的部分开始，不需要一开始就承诺做完整款游戏。

| 方向 | 可以先做的小任务 |
| --- | --- |
| 玩法与数值 | 设计一个有趣的单人挑战，讨论繁殖成本和评分规则 |
| 游戏模拟 | 让采集、搬运、回巢这条链路跑起来 |
| AI 与程序运行 | 设计职业指令，做计算预算和程序版本对比 |
| 画面与交互 | 做像素地图、蚂蚁移动和效率面板 |
