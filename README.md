# ANT MIND · 蚁智（暂定名）

**做一个给 AI 玩的蚂蚁游戏。人定方向，AI 写程序，蚁群用搬运效率证明策略。**

这是一个简约像素风的桌面蚁群经营游戏。你在 Codex 聊天中提出发展方向，Codex 连接游戏，编写工蚁算法、安排增员和升级；你可以观察蚂蚁为什么这样行动，再要求它优化。

> 先不要增加蚂蚁。看看它们为什么空跑，改进信息素策略，让每分钟运回来的资源更多。

## 当前状态

**最小版规划已于 2026-11-05 经发起人确认。本仓库目前只有规划文档，还没有可运行游戏或实际 Agent 接入。已按最新要求改为无游戏引擎架构，游戏源码尚未开始。**

完整范围、数值与验收以 [最小游戏规格](docs/MVP_SPEC.md) 为准。

## 第一版怎么玩

1. 一张无障碍平面地图、一个蚁巢、一种工蚁，资源持续随机出现。
2. 工蚁按程序寻找、拾取、搬回和交付资源。
3. 工蚁共用一份算法，各有独立记忆；通过一种通用信息素协作。
4. 运回的资源可以增加工蚁，或升级共同大脑，提高指令预算和决策频率。
5. 玩家查看程序、个体目标和决策记录，在 Codex 中要求单轮或多轮优化。

游戏不限时，可存档继续；没有饥饿、死亡或维持消耗。算法升级不改变移动速度、负载和感知范围。

## 已确认的方案

| 内容 | 选择 |
| --- | --- |
| 平台与技术 | Windows x64，C# / .NET 10 LTS + Avalonia Desktop |
| Agent 接入 | 当前 Codex，通过项目级 MCP；尚未实现 |
| 模式 | 单人、不限时经营，持续发展升级 |
| 算法 | 受限文本语言，同类共享程序、个体记忆独立 |
| 信息 | 玩家看全图，工蚁局部感知；Agent 可切换全图／仅已发现 |
| 成长 | 增员与 5 级共同大脑，花费公共仓库资源 |
| 调试 | 只读程序、版本回滚、个体决策与预算记录 |
| 运行 | 内置默认程序，断开 Agent 后继续；暂停、单步、倍速、手动存档 |

同一地图、同一初始状态下，换一套程序能多运回多少资源，是我们首先要验证的体验。

## 扩展与共同开发

模拟核心、工蚁程序解释器、桌面界面和 MCP 适配独立组织。规则与配置可单独扩展，核心可无界面运行；新增 Agent 使用同一工具契约。完整边界见 [技术架构](docs/ARCHITECTURE.md)。

## 一起开发

可以从画面交互、模拟规则、程序解释器或 Agent 接口中选择一个方向。开发路线已拆成可演示、可验收的阶段，人员与排期尚未约定。欢迎在 Issues 讨论，再以小 PR 推进，见 [协作说明](CONTRIBUTING.md)。

第一版先做好观察、改程序和经营闭环；多个职业、障碍、战斗、天气、排行榜与多人竞技留待后续另行讨论。
